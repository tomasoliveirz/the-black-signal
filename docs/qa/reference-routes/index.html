Local reference proposal · 15 November 2026 · Foundry + Ashfall

This review shows real browser/WebGL captures and diagrams exported from the authoritative layout. It is a reviewable draft, with no production deployment or owner visual approval. The other four maps retain their layouts.

The previous code gave the final relay and extraction almost the same location. The proposed layouts create separate destinations, real route choices, and signs that explain when supplies and power unlock. Phase durations and supply budgets stay the same.

Locked objects / Objetos bloqueados

Future supplies remain visible as sealed cases. Looking at them shows the unlock day without an “E” action. A future transmitter explains when power arrives. The UI reads the same phase table as the rules; the server still enforces access. The following captures use an isolated test server with an explicit phase/teleport fixture, not a normal player session.

Os recursos futuros aparecem como caixas seladas. Ao olhar para eles, o aviso indica o dia de abertura, sem pedir para carregar em E. Os transmissores explicam quando recebem energia. Os avisos usam a tabela das fases; o servidor continua a validar o acesso. Estas capturas usam um servidor de teste com fase e posição preparadas, não uma sessão normal de jogador.

Evidence & open gates / Provas e critérios em aberto

  • 62 server/asset cases passed. Route centre lines sampled every 0.25 m with human 0.42 m and monster 0.82 m collision radii.
  • Both Foundry rear exits tested independently; evacuation remains reachable with either exit blocked.
  • Real WebGL floor rays match authoritative street 0 m, sidewalk 0.08 m and curb 0.12 m.
  • Six actual WebGL worlds load without required-request failures or runtime errors.
  • 16 six-bot rounds: 0 stuck matches, leaked private fields or premature blackouts. Echoes won all 16; no human balance approval.
  • The previous immutable build failed the full 30-minute frame-p99 budget (29.9 ms versus 25 ms). The separate eight-minute diagnostic measured p99 19.4 ms, worst 333.6 ms; it does not replace the full gate. New route performance has only per-image draw counts.
  • Owner visual approval, six-human chase/balance, real microphones/Internet impairment, independent security and asset rights review remain open. No issue is marked complete from screenshots alone.
