# Figure GPU lifetime regression

The 30-minute pre-fix runtime capture showed rising geometry/texture counts between rounds. That observation alone was not a memory-leak proof. An isolated actual WebGL reproduction then built and removed two humans and a Knocker repeatedly: after the first warm cycle, each additional cycle retained four geometries and ten skeleton textures (162→178 geometries, 16→56 textures across five cycles). The previous removal path detached roots without disposing their per-instance GPU resources or pruning style registries.

Figures now own an idempotent dispose path. It releases generated geometry, cloned skeleton textures and Knocker-specific dab material, prunes detached style entries and removes queued/delayed attachment. Procedural fallbacks are released after the real rig attaches. Source glTF geometries remain shared in the loader cache and are never disposed by an instance. Survivor cloning uses SkeletonUtils too so any skinned rig has independent skeleton ownership. Remote-view reset and local slot replacement call the lifetime API.

`npm run test:figures` performs five real Chromium/WebGL cycles, verifies counts plateau after warm-up, keeps a live survivor attached, checks original source geometry never receives disposal, and disposes before an async attachment to prevent resurrection. Before evidence fails; after evidence stays at 139 geometries and six textures for all five cycles. See `figures/before.json` and `after.json`. The browser case joins CI; remote success must be checked.

This fixes the reproduced figure lifetime fault, not every possible renderer cache. Source caches and the shared procedural material remain intentionally alive. Map-theme material eviction and broader long-run profiling remain separate. The earlier 30-minute capture predates this fix and must not be presented as a post-fix soak. Revert this commit as one unit (source ownership tracking, figure disposal and game removal call sites). No art/rules/balance changes, main merge or production deployment.
